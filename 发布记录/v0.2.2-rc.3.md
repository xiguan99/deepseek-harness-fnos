## 与 rc.2 的差异（官方 Release Notes）

1. **新增实验性「DeepSeek 会话导入」插件**：可将 DeepSeek App 或网页版的历史会话导入工作区并继续对话。
2. **修复 Windows 桌面版应用内更新**可能失败、无法自动重新打开的问题（对 fnOS 无直接影响）。
3. 运行时 npm 安装 671 包，依赖整批 rc.2 → rc.3（构建日志）。

## 本版改动（本仓库）

1. `VERSION` / `RUNTIME_VERSION` / `fnpack/manifest` 版本改 `0.2.2-rc.3`。
2. `README.md` 血缘表新增 rc.3 行（rc.2 行去掉「当前」）、版本小节同步。
3. **`fnpack/cmd/main` 新增 502 启动兜底**：给整个进程树（含 billion-context 边车）注入
   `NODE_OPTIONS=--network-family-autoselection-attempt-timeout=2000`。
   根因：Node `autoSelectFamily` 默认 250ms 等待会误杀慢 SYN，在 IPv4/IPv6 双栈解析时造成上游 502/upstream-timeout；
   写在启动层（`cmd/main`）而非插件配置，插件升级重装不会覆盖。若外部已设同名 NODE_OPTIONS 参数则不重复注入。
