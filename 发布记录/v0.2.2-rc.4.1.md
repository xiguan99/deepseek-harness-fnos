## 本版改动（本仓库）

1. `fnpack/app/bin/skill/` 整体替换为 fnos 技能 `0.6.2`（目录名 `fnos-cli`，启动器 `scripts/fnos-cli`；新增随包二进制 `bin/fnos-cli-0.6.2-linux-x64.gz`）。
2. `internal/skill/config.go`：`ApplyBuiltinSkillConfig` 兼容新布局（`scripts/fnos-cli` 与旧 `scripts/trim-cli` 双路径 chmod、`bin/` 逐文件 chmod）；新增 `seedFnosCliCache`——首启把随包 gz 校验（大小 + sha256，读技能根 `runtime-manifest.json`）后解到启动器缓存 `~/.cache/fnos-cli/0.6.2/linux-x64/fnos-cli`，幂等；首跑不再联网下载 CLI。
3. `internal/api/skill_auth.go` 重写为两段式授权：`login --authorize-only` 一次性取 `authorization_url` → 用户授权 → `login --code` 确认；`parseFnosCliJSON` 流式括号平衡解析（0.6.2 输出为多行美化 JSON，旧单行解析失效）；`logout` 追加清理 CLI profiles；状态刷新用 `system info` rc 判授权。前端 API 契约与弹窗不变。
4. `VERSION` → `0.2.2-rc.4.1`（`RUNTIME_VERSION` 保持 `0.2.2-rc.4`）。
