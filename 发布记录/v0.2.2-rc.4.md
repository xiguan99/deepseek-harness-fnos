## 为什么升到 rc.4

官方 0.2.2-rc.4 于 2026-11-17 发布（npm `next`，构建时）。此版为预览线常规跟进。

## 与 rc.3 的差异（官方 Release Notes）

1. **优化模型请求收到异常消息响应时的表现**。
2. **修复 LiveShare 在桌面端无法创建分享的问题**。
3. 运行时 npm 安装 671 包，83 个 `@deepseek-ai/*` 依赖整批 rc.3 → rc.4，无增删（`package.json` 实测对比；主包 `lib/`、`src/` 文件级零差异）。
4. 审计（面板浮层相关）：官方 rc.3…rc.4 改动**不含任何 menu/overlay/panel/floating 相关条目**（对照 rc.2 那条「菜单与浮层换了新的定位接口」），影响=无；影子浮层实测正常（见下）。

## 本版改动（本仓库）

1. `VERSION` / `RUNTIME_VERSION` / `fnpack/manifest` 版本改 `0.2.2-rc.4`。
2. `README.md` 血缘表新增 rc.4 行（rc.3 行去掉「当前」）、安装文件名与版本小节同步。
3. 无代码改动（`cmd/main` 的 502 启动兜底为 rc.3 引入，随包继承）。

## 已知事项

1. 冒烟唯一失败项「config.json 版本为 0.2.2-rc.5（期望 0.2.2-rc.4）」：冒烟的在线升级步骤走 npm
   `next` 通道，构建期间 `next` 已漂到 rc.5（2026-11-18 官方发布），在线升级实装 rc.5 属预期行为，
   **非 rc.4 包缺陷**（rc.4 包的安装/覆盖升级/停止/卸载链路全部通过）。
2. 官方 0.2.2-rc.5 已于 2026-11-18 发布（npm `next`：DeepSeek 模型改用 DeepSeek 服务端搜索）。
3. 影子实例上 2399 反代子进程驻留情况属影子环境观察项；生产反代不受影响。
4. 随包运行时不含 `@deepseek-ai/dsh-experimental-schedule-bundle`（生产 profile 里有），启动对齐逻辑会跳过它并保持原样。
5. UI 控制台存在同类无害告警（rc.2/rc.3 亦存在）。
